# Viewer — экран квартиры (статический режим)

Статический режим по [deploy.md](../../../docs/deploy.md) §2: читает `model/latest.json` из папки запуска и отдаёт эталон 54541 из бандла по `?src=fixture`. Это ещё не прогулка: центральная область показывает исходный план с разметкой из модели, а 3D-сцена помечена как не построенная, пока не подключён Builder.

## Что на экране

- **План с разметкой.** Стены, двери, окна, вход и якоря помещений рисуются прямо из `FlatModel` через `plan.pxPerMeter` (`src/plan-overlay.ts`). Это слой интерфейса для выбора и подсветки, не Builder и не Geometry Core: площади, грани и коллизии не считаются. Без масштаба показывается только картинка, без картинки — схема стен, без того и другого — честное пустое состояние.
- **Помещения.** «Вся квартира» и список из модели; выбор подсвечивает якорь на плане и стены, на которые смотрят фотографии помещения.
- **Фотографии.** Привязки берутся из `assets.*.room`; если привязок нет, показывается общая галерея. Крупный просмотр с навигацией и клавиатурой.
- **Допущения и диагностика.** Полоса под сценой и окно «О модели»: источник, кто размечал, масштаб и высоты с основанием, открытые вопросы из `meta.question`, отчёт Validator (`validation/rev-NNN.json`), если он есть, иначе явное «не проверено».
- **Недоступное.** «Прогулка» показана выключенной с причиной; «3D-сцена» открывает пустую three.js-площадку с подписью. Никакого имитированного прогресса.

## Зависимости

Viewer использует публичный пакет `@flatwalk/contract` (`file:../contract`, экспорт из `dist/`). Перед запуском контракт должен быть собран:

```text
cd modules/contract && npm run build
cd ../viewer && npm install --workspaces=false
```

Пакет ещё не прописан в корневых скриптах репозитория (общий `package.json` и lockfile этой задачей не менялись).

## Запуск

```text
cd modules/viewer
npm run dev
```

Откройте http://127.0.0.1:5173/ (если порт занят прототипом — `npm run dev -- --port 5180`).

По умолчанию Vite читает локальную демо-папку `demo-run/` (синтетическая модель `viewer-synthetic`, не эталон 54541).

Папка запуска CLI:

```text
FLATWALK_RUN=/absolute/path/to/runs/54541 npm run dev
```

Viewer запросит `/model/latest.json`, `/validation/rev-NNN.json` и относительные ассеты (`/materials/…`) из этой папки.

Эталон 54541:

```text
http://127.0.0.1:5173/?src=fixture
```

Читает `fixtures/54541/flat.model.json`, `plan.png` и `photos/` рядом. Если эталона нет, страница явно пишет, что файл недоступен.

Сборка и проверки:

```text
npm test
npm run build
npm run preview
```

## Демо-папки

- `demo-run/` — валидная синтетическая модель `viewer-synthetic` (не 54541).
- `demo-invalid/` — JSON, который контракт отклоняет.
- `demo-missing-plan/` — валидная модель со ссылкой на отсутствующий план.

```text
FLATWALK_RUN=$PWD/demo-invalid npm run dev
FLATWALK_RUN=$PWD/demo-missing-plan npm run dev
```

## Состояния

- загрузка;
- нет `model/latest.json` или нет эталона 54541 — с переходом на другой источник и повторной проверкой;
- JSON не проходит `@flatwalk/contract` — замечания контракта под раскрывающимся блоком;
- модель есть, исходный план не открылся — схема стен из модели или пустое состояние.

## Подключение Builder

Сцена монтируется лениво в `#scene-slot` через `mountScene` в `src/main.ts` (сейчас `mountScenePlaceholder`). Builder должен вернуть `{ dispose }` и получить контейнер; переключатель «План / 3D-сцена» и статусная строка уже на месте.
